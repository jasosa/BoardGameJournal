Export and import in Settings

You can download everything you have recorded as one JSON file, and put that file back into an empty account. That covers your games and their facts, every copy (archived ones too), status history, ratings and thoughts. Cover images are not in the file; the file notes which games had one. Import works only into an empty account and saves everything or nothing.

There are three ways to place this in Settings. They differ in where it lives (inline, its own page, or a dialog) and how much room the import check gets. I recommend Option A (inline section). Every state of Option A is drawn in the last part. Sample data: a library of 214 games. The Settings page has no cover art on purpose: covers are not part of the file, and imported games arrive with their initial tile.
